# doubao-daily-checkin

豆包工作（Doubao Work）每日签到、活动任务、额度领取的 AI Agent 技能。默认一键全量执行：**签到 → 领掉所有「立即领」→ 做完所有「去完成」→ 逐项领回额度 → 核对累计额度与奖励进度**，不需要用户逐项点名。

## 这个技能解决什么

豆包工作活动页（「从容开工 用豆包工作 额度天天送」）里有三类卡：

- **签到**：每天一次，点「立即签到」即到账；
- **直接领取类**：卡片右侧是「立即领」，点一次就领到；
- **任务生成类**：卡片右侧是「去完成」，如生成表格、生成 PPT、每日完成一项工作任务、把零散资料整理成一份文档。

任务生成类如果只在普通对话里做完，活动页不会判定完成、也就领不到额度；直接领取类如果没人盯着点，额度也一直挂在那。本技能把「签到 → 领「立即领」→ 逐个点「去完成」进入任务上下文 → 真正做出成品 → 回活动页领奖励 → 核对累计额度」整套流程固化下来，**默认全部做完**，让 Agent 每次都能一口气收干净。

## 默认执行策略

1. **先领现成的**：活动页上凡是「立即领」的卡片，先逐个点掉，能领多少领多少；
2. **再做任务**：所有「去完成」类任务一律进入任务上下文做出来，做完回活动页领对应额度；
3. **全量循环**：按卡片顺序一项一项做，做完一项领一项，直到页面上不再出现「去完成」或「领奖励」；
4. **只跳过必须本人操作的**：邀请成员、本人扫码认证、绑定手机号等无法代做的，标注原因后跳过，其余全部做完；
5. **失败两次即止**：某个任务反复进不去上下文或产物始终不被判定完成，记录原因后跳过，不无限重试。

用户明确说「今天只签到」「不要做任务」时，才降级为仅签到并核对额度。

```
doubao-daily-checkin/

```

## 安装

把整个 `doubao-daily-checkin` 目录放到 Agent 的技能目录即可，例如：

- 个人技能：`<workspace>/.user_skills/doubao-daily-checkin/`
- 内置技能：`<workspace>/.skills/doubao-daily-checkin/`

目录内保持 `SKILL.md` 位于根层，技能即可被识别和加载。

## 使用

选中技能后直接说需求，例如：

> 完成今天的豆包签到，把能领的任务全领了、能做的任务顺手做完，最后领积分。

> 一键做完今天活动页所有任务并领取全部额度。

甚至什么都不说，直接触发技能，也会按默认全量流程跑一遍。

只想签到时明确说明：

> 今天只签到，不用做任务。

技能按下面的顺序执行：

1. 打开活动页（固定地址 `https://www.doubao.com/pc/agent-explore?enter_method=fixed_entry`）；
2. 完成签到（当天只签一次）；
3. 读任务卡状态与累计额度；
4. 领掉全部「立即领」；
5. 逐个进入任务上下文，把「去完成」任务做成成品；
6. 回活动页逐项「领奖励」，每领一项核对一次累计额度；
7. 汇总回报：今日到账、累计额度、距下一档还差多少、已领／未领／无法代做清单。

## 关键口径（本技能的核心）

- 任务生成类必须**先按住 Ctrl 点击「去完成」**进入任务上下文，输入框会预填提示词并带对应技能标签，此时发送才算活动任务；
- 普通单击「去完成」只会弹「试试这些灵感」浮层，浮层里的胶囊点了没反应，这条路径不要重复尝试；
- PPT 类任务若 Ctrl+点击仍只弹浮层，则 Ctrl+点击浮层内对应的胶囊卡进入上下文；
- 进入成功的判据：出现新任务页、输入框有预填内容、右侧技能栏出现对应标签，三者缺一说明没进上下文；
- 输入框是 contenteditable：点击输入框 → Ctrl+A → 剪贴板粘贴覆盖，比逐字输入稳；
- 任务做完的判据是出现「任务已完成，立即领取活动激励额度 / 去领取」通知；
- 领取方式：点通知「去领取」，或回活动页刷新后点卡片上的「领奖励」，直到出现「领取成功」；
- 每领一项都核对一次「累计获得额度」，确认数值真的增加；
- 需邀请成员、需本人扫码认证的任务无法代做，如实标注。

## 边界说明

- 只操作用户本人已登录的豆包工作客户端，不处理账号、密码、验证码；
- **默认全量执行**（签到＋领任务＋做任务＋领积分），只有用户明确要求「只签到」时才缩减范围；
- 额度、进度数字一律以页面实时显示为准，页面没展示的不做推测；
- 网页端完成后台判定不生效，任务必须在客户端活动页进入的任务上下文里做。
