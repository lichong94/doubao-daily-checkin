# doubao-daily-checkin

豆包工作（Doubao Work）每日签到、完成活动任务、领取额度、核对奖励进度的 AI Agent 技能。

## 这个技能解决什么

豆包工作活动页（「从容开工 用豆包工作 额度天天送」）里有两类任务：

- **直接领取类**：卡片右侧是「立即领」；
- **任务生成类**：卡片右侧是「去完成」，如生成表格、生成 PPT、每日完成一项工作任务、把零散资料整理成一份文档。

任务生成类如果只在普通对话里做完，活动页不会判定完成、也就领不到额度。本技能把「点去完成 → 进入任务上下文 → 真正做完任务 → 回活动页领奖励 → 核对累计额度」这一整套流程固化下来，让 Agent 每次都能照做，不再走弯路。

## 技能包含

```
doubao-daily-checkin/
└── SKILL.md    # 技能主文件：触发条件、核心口径、完整执行流程、约束
```

## 安装

把整个 `doubao-daily-checkin` 目录放到 Agent 的技能目录即可，例如：

- 个人技能：`<workspace>/.user_skills/doubao-daily-checkin/`
- 内置技能：`<workspace>/.skills/doubao-daily-checkin/`

目录内保持 `SKILL.md` 位于根层，技能即可被识别和加载。

## 使用

选中技能后直接说需求，例如：

> 帮我完成今天的豆包签到，核对累计额度和奖励进度。

> 帮我把能领取的任务全部领取，能做的任务顺便做了，然后领对应积分。

> 今天只签到，不用做任务。

技能会按下面的顺序执行：

1. 打开活动页（固定地址 `https://www.doubao.com/pc/agent-explore?enter_method=fixed_entry`）；
2. 完成签到（当天只签一次）；
3. 读任务卡状态与累计额度；
4. 用户要求领奖时，逐个进入任务上下文把任务做出来；
5. 回活动页领取对应额度；
6. 汇总回报：今日到账、累计额度、距下一档还差多少、已领/未领清单。

## 关键口径（本技能的核心）

- 任务生成类必须**先按住 Ctrl 点击「去完成」**进入任务上下文，输入框会预填提示词并带对应技能标签，此时发送才算活动任务；
- 普通单击「去完成」只会弹「试试这些灵感」浮层，浮层里的胶囊点了没反应，这条路径不要重复尝试；
- PPT 类任务若 Ctrl+点击仍只弹浮层，则 Ctrl+点击浮层内对应的胶囊卡进入上下文；
- 任务做完的判据是出现「任务已完成，立即领取活动激励额度 / 去领取」通知；
- 领取方式：点通知「去领取」，或回活动页刷新后点卡片上的「领奖励」，直到出现「领取成功」；
- 每领一项都核对一次「累计获得额度」，确认数值真的增加；
- 需邀请成员、需本人扫码认证的任务无法代做，如实标注。

## 边界说明

- 只操作用户本人已登录的豆包工作客户端，不处理账号、密码、验证码；
- 默认只签到、核对额度；做任务和领其他奖励需要用户当次明确要求；
- 额度、进度数字一律以页面实时显示为准，页面没展示的不做推测。
